# ChargeSmart EV Charging Station Optimizer

## Run
1. Extract this ZIP.
2. Open the `ChargeSmart_Updated` folder in VS Code.
3. Open `index.html`.
4. Run with the Live Server extension, or open `index.html` in a browser.

## Features
- EV driver dashboard with recommended stations, demand chart, filters and booking form.
- Find Stations and My Bookings pages.
- Station Owner Console with charger toggles, add charger, illustrative metrics, booking table and CSV export.
- Reports & Analytics page.
- Responsive desktop/mobile layout.

## Important
This is a front-end demonstration. It uses sample data stored in JavaScript memory. It has no backend/database, live charger connection, real-time station feed or payment processing. Refreshing the page resets demo changes.
